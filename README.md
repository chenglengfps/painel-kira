# Painel Kira

Fila de postagens do **Yggdrasil Animes**.

- Busca anime no AniList
- Legenda no formato do canal
- Posta no Telegram
- Fila com no máximo **2 posts por dia** (horários aleatórios, 9h–22h Brasília)
- Atalhos WhatsApp / Threads

Código de estudo extraído do app. **Token do bot não está neste repositório.**

Leia **[COMO-FUNCIONA.md](COMO-FUNCIONA.md)**.

## Segurança

Use `.env` (`TELEGRAM_BOT_TOKEN`). Não commite o token.

Se publicar o painel, deixe o link privado — não há login.
